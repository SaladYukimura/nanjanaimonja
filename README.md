# ナンジャナイモンジャ

へんな生き物に名前をつけて、二度目に出たら早く呼んだ人が総取りする、名前つけ早押しカードゲーム。
スマホ1台をみんなで囲んで遊びます。

**遊ぶ → https://saladyukimura.github.io/nanjanaimonja/**

Safari で開いて「ホーム画面に追加」すると全画面で起動し、以降は電波が無くても遊べます。

## あそびかた

1. 手番の人が「めくる」を押す。3・2・1 のあとにカードが表になる
2. **はじめて出た顔**なら、めくった人が好きな名前をつけて全員で覚える
3. **前に出た顔**なら、その名前を早く呼んだ人の勝ち。積まれたカードを全部もらえる
4. 山札がなくなったら終了。枚数が一番多い人の勝ち

2〜8人。カードは12種 × 5枚 = 60枚。

## これは何

市販のボードゲーム『ナンジャモンジャ』（すごろくや）で遊ぶのが好きで、
そのルールを自分たちのスマホで遊べるように個人で作ったものです。
**販売元・権利者とは一切関係のない非公式の個人制作で、収益化していません。**
イラストはすべてこのプロジェクトのために新規に用意したもので、本家のカードとは別物です。
